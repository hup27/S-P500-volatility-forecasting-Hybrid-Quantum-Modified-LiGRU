
# A Hybrid Quantum-Modified Neural Network for S&P 500 Stock Volatility Forecast

This repository contains the research paper and source code for a project investigating hybrid quantum-modified machine learning for S&P 500 stock volatility forecasting.

## Research Paper

**Title:** A Hybrid Quantum-modified Neural Network for S&P 500 Stock Volatility Forecast

**Publication:** Accepted for Publication in the National High School Journal of Science (NHSJS)

The paper explores the integration of variational quantum circuits (VQCs) with a modified Light Gated Recurrent Unit (LiGRU) architecture for financial time-series forecasting.

## Methodology

The project investigates a hybrid quantum-classical recurrent neural network that combines:

- **Modified LiGRU:** A lightweight recurrent neural network for sequential financial data.
- **Variational Quantum Circuits (VQCs):** Parameterized quantum circuits used to transform input features.
- **Volatility Forecasting:** Evaluation of model predictions on S&P 500 financial time-series data.
